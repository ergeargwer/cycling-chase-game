## 1. GitHub Pages 無法進入遊戲（無限載入）

### 現象
https://ergeargwer.github.io/cycling-chase-game/ 一直停在「智慧騎行／追逐模式」載入畫面，canvas 從不出現。

### 根因
- 入口 `index.ts` 使用 **top-level `await app.init()`**
- Vite 將 Pixi WebGL／WebGPU renderer 拆成獨立 chunk，且 chunk **static import 回主 entry**
- 主模組因 TLA 未評估完成 → 動態 import renderer 永遠等待 → **ESM 循環死鎖**
- 本機 dev 不一定踩到相同拆包，故本機正常、Pages 卡死

### 修復
- 將啟動包進 `async function bootstrap()`，入口不再使用 TLA
- 載入失敗時顯示錯誤與重新整理
- 15 秒無 canvas 時提示載入逾時

### 關鍵檔案
- `src/renderer/index.ts`
- `src/renderer/index.html`

## 4. 現代／復古視覺風格架構

### 需求
- 進 Chase **前** 選擇 `modern` | `retro`，整場鎖定
- **不**支援遊戲中熱切換；回主選單後再選
- 玩法邏輯不變，只換資源與渲染

### 狀態流
```
主選單 → StyleSelect（modern|retro）→ 計畫/主題 → ChaseScene（sessionStyle 鎖定）
```

### 主要模組

| 檔案 | 職責 |
|------|------|
| `game/visual-style.ts` | 型別、路徑、視差常數、場景 manifest、復古幀格 |
| `game/asset-loader.ts` | primary → fallback + console.warn + nearest |
| `game/retro-parallax.ts` | L0–L4 無縫 tile／中景／路肩 props 視差 |
| `game/game-state.ts` | `visualStyle` / `setVisualStyle` |
| `game/themes.ts` | `getTheme(id, style)` |
| `scenes/style-select-scene.ts` | 風格選擇 UI |
| `docs/architecture-visual-style.md` | 架構說明 |

### 復古渲染
- `texture.scaleMode = 'nearest'`
- CSS `image-rendering: pixelated`（`data-visual-style=retro`）
- CRT 掃描線疊加
- 缺復古 PNG 時回落 modern／Graphics，仍套用 nearest + CRT

### 除錯 URL
- `?screen=style`
- `?style=retro&screen=chase&theme=redlady`
